# Задание №4. Квадратный многочлен ax² + bx + c

## Вариант 14

Программа считывает коэффициенты `a`, `b`, `c` квадратного многочлена, затем символ:

| Символ | Действие |
|--------|----------|
| `N` | Вывод фамилии и имени студента на английском |
| `g` | Вычисление корней квадратного многочлена |
| `z` | Перевод температуры из °C в °F |

### Особенности решения корней:
- `a=0, b=0, c=0` → x — любое действительное число
- `a=0, b=0` → корней нет
- `a=0` → линейное уравнение, один корень
- `D < 0` → нет действительных корней
- `D = 0` → один корень
- `D > 0` → два корня
